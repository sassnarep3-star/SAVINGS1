Why the Big Four look different

APY unavailable from an official page for the user's market. Chase shows its savings rate table only after a valid 5-digit ZIP code is entered. Bank of America's page renders fee and minimum-balance values as “$XXXX” to automated readers. Citi's rate table renders a dynamic placeholder (its footnote dates the APY to 10/21/2026 but the number is injected at runtime). Wells Fargo does print 0.01% APY — but only for the page's default market (CA 94105), not for New York. All four APYs are therefore left blank and excluded from every return calculation. See Flagged for review.
