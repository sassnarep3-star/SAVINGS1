VERIFICATION RULES

What “verified” means here

  • Rate figures, balance thresholds, fee terms, offer windows and account opening requirements are included only when stated in an official bank source linked on the page.
  • Each published table row includes at least one source link. Projection rows link to the bank page containing the input rate.
  • When the source is missing, location-locked, inaccessible, stale or contradictory, the affected value stays blank or is clearly labeled stale/qualified and appears on Flagged for Review.
  • Search engines were used to locate sources; non-bank and non-government sources were not used to supply account values or fill missing data.
  • FDIC coverage rules are supported by FDIC.gov, not bank marketing copy alone.

RETURN FORMULAS

Transparent arithmetic

  • Annual return for a one-year period: starting deposit × published APY, assuming the APY is unchanged for the full year, no fees, no withdrawals, and interest remains deposited.
  • Multi-year illustration: starting deposit × ((1 + APY)n − 1), with APY held constant and interest retained annually. This is an explanatory scenario, not a bank quote.
  • Illustrative one-year principal headroom at 3.25%: $250,000 ÷ 1.0325 = $242,130.75, rounded to cents. This assumes no other same-category deposits and an unchanged rate; it is not a guaranteed insured starting amount.
  • Displayed estimates are rounded to cents (or nearest dollar where a range is shown). Citi's APY range is a source-published dated range and not a current standard APY.
